UI pipeline 启动必须有仓库根目录下的 `devsupport/reports/budget-current-gateway.json` 有限预付授权；与评测入口共用对应的 `.accounting.json` 账本。启动只读取并校验本地文件，不查询余额或调用模型；每次付费阶段调用前检查余额、累计用量及保留额度，授权/账本无效或余额不可用时关闭付费路径，不自动充值或扩大授权。所有 UI profiles 共用守卫，provider 调用在进程内串行执行。共享账本不是跨进程的原子花费预留，禁止同时运行付费 UI、评测或探测；外部共享密钥用量及在途请求意味着它不提供精确的硬金额上限。

查询分解在原有触发策略之后检查标识符容量：原问题的任一必保留精确标识符超过 512 字符，或去重后的名称字符数之和超过 1,024 时，跳过分解调用，保留首轮排序证据并继续正常装箱、最终 gate 和回答。`always` 也受此必需检查约束；trace 记录 `triggered=false`、`reason=identifier_budget_infeasible`，而非模型失败。检查只计算名称长度，不估算分隔符或装箱；通过不代表分解一定可行。`preflight_policy` 及 runtime hash 记录策略版本，原有标识符提取、输出校验和长度限制不变。
