# 技术文档检索组件

此目录保留技术文档检索、回答与快照引用所需的实现，使用 FAISS、BM25S 和 RRF，并提供可配置的重排、有限复检和证据门控。

普通用户先按根目录的 [安装与使用指南](../GETTING_STARTED.md) 启动文档问答、上传自己的资料。普通上传使用原生知识库流程，不需要先启动这个独立组件。

此组件需要自行准备文档索引、模型服务和回答服务配置；源码不包含预建索引或模型权重。`src/devsupport/` 是运行实现，`scripts/` 保留索引构建、模型下载和服务启动入口，`configs/` 提供检索配置，`tests/` 保留运行逻辑的回归检查。

`serve_pipeline.py` 的专用服务要求配置调用预算文件；文件属于运行时状态，未随源码分发。更换服务商时，需要按自己的服务修改 provider 配置和凭据路径，不能直接使用他人的路径或账号。

普通用户不需要改动这些实现文件。问题、检索到的文档片段可能发送给配置的回答服务；引用需核对原文。可选模型的许可证见 [来源说明](../SOURCES.md)。
