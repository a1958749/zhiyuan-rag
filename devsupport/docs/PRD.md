## 用户与核心场景

面向使用 LangChain 等开发工具的开发者，针对 API 名称、错误码、参数、版本差异和排障问题检索固定知识快照，给出有来源的回答。用户可以在 DocsGPT 原生聊天界面查看来源快照、打开原始 URL，并使用原生上传功能。快照不代表当前最新版文档。

期望流程：输入问题 → 检索相关原始证据 → 必要时有界扩展检索 → 独立证据门控 → 回答、澄清或证据不足 → 查看引用。系统不自动执行修复命令。

## 范围与约束

- 保留真实 DocsGPT UI、权限和原生来源体系；评测与在线共用核心检索实现。
- 全量保留 49,514 原始语料行；按可审计 `official_last` 策略生成 49,505 个官方唯一 ID。原文、URL、字节偏移保留，禁止把答案、nuggets 或 qrels 加入在线语料。
- 203 题固定分为 DEV 53 / 本地留出 TEST 150；只用 DEV 选择模型、阈值和提示词。
- 候选每路最多 50，RRF 常数 60；两个重排器使用同一 50 项池。扩展最多两条子查询、最多一轮，并保留原查询。
- 身份、成本、失败、降级和截断均需记录；无证据的模型质量、用户数和商业收益不得宣称。

不在范围内：界面重写、新认证系统、自动执行修复、GraphRAG、多模态、长期记忆、微调和在线爬取。

## 必须披露的偏差

原设计为 4,000 个生成模型 token；当前统一实现为 4,000 `cl100k_base_proxy_v1` 代理 tokens，使用 SHA256 校验的上游内置 tokenizer，且整块保留、超长跳过。网关底层 tokenizer 未知，仍不能声称精确生成 token 预算。旧 4,000 UTF-8 字节方案造成严重证据不足，已取代并保留历史诊断。

新预算对所有方法一致。DEV 53 题装箱覆盖诊断显示 H0 为 0.33014、H1 为 0.31402；H1 的排名指标优势不等于装箱后或回答质量优势。完整 DEV12 AI 评价中，H0 的含失败整体效用为 2.2333/3，高于 B0/H1/C 的 1.3000/1.2000/1.6333，因此下一阶段选择 H0、不加重排。该小样本经过诊断性富集，历史接口失败和单次生成随机性未被隔离；这不是最终 TEST 结论，不得将预算修正收益归因于检索算法。

当前授权网关请求名 `deepseek-v4-pro`，返回名 `claude-opus-4-8`，底层身份未验证。早期其他模型 smoke 不可混入当前生成对照。网关曾多次限流；正式 DEV 四组生成已在保留失败记录的前提下恢复完成。AI 评分 v4 已覆盖全部 12 题、35 份成功回答，13 次原始运行错误仍计入整体效用分母；此前三轮评分协议故障及费用保留，不合并重复评分。生成与评分可能来自同一底层模型，不能称独立模型或真人验证。65 秒共享间隔机制不等于供应商限额已确认。具体阶段、费用和故障依据以 [实验记录](EXPERIMENTS.md) 为准。

“Coverage@10 相对 B0 +5 个百分点”和“alpha-nDCG@10 相对 H0 +0.03”为原始目标假设。H1 的第一项点估计达到但区间跨零；C 相对 B0 的 Coverage@10 差值为 +9.52 个百分点且区间为正。H1/C 相对 H0 的 alpha-nDCG 增量均未达到 +0.03。以上仅 DEV 诊断，产品完成必须等上述缺口取得独立证据。
